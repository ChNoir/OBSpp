# I18n

La couche `I18n` gère les traductions du projet avec deux modes : "cold" (compilé / statique) et "hot" (runtime, édition rapide).

## Rôle

- charger les traductions maîtres depuis `local/*.json` (cold) ;
- exposer des contextes locaux pour remplacer des tags dans les textes ;
- fournir une route statique pour accéder aux fichiers locaux (`/i18n/local`).

## Principales fonctions

- `I18n.setLocal(local)` : charge le fichier `local/<local>.json` en cold map.
- `I18n.createColdContext<T>()` : retourne un `I18nColdContext<T>` pour accéder aux clés cold.
- `I18n.createHotContext<T>(local)` : charge (ou récupère) un `I18nHotContext<T>` basé sur `<local>.hot.json`.

## Exemples rapides

```ts
// Récupérer une traduction cold
const i18n = I18n.createColdContext<{ greeting: { name: string } }>()
const text = i18n.get('greeting', { name: 'Alice' })

// Charger un local différent
await I18n.setLocal('en')

// Créer un contexte hot pour un local spécifique
const hot = await I18n.createHotContext<{ greeting: { name: string } }>('en')
hot.get('greeting', { name: 'Bob' })
```

## Où placer les fichiers

- `local/<lang>.json` : traductions cold (déployées)
- `local/<lang>.hot.json` : traductions hot (édition locale)
